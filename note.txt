Learning Object are:

- Build REST APIs using Minimal APIs, controllers, and layered architecture

- Multiple programming languages support

- Cross-platform development
- Open-source and community-driven
- Large ecosystem and tooling support

Evolution of the .NET platform
2002 - 2016 -2020

Platform, Runtime, SDK and Framework
- .NET Platform - The ecosystem for building and running application
- .NET Runtime - Runs apps and manages memory GC, and exceptions
- .NET SDK - Tools to create build, test, run and publish 
- Framework - ASP.NET for web, APIs Blazor for interactive web UI
